# TaskFlow Pro

팀 업무 관리 풀스택 웹 앱. "지금 누가 뭐 해?"가 사라지게 한다.

## 기술 스택
- 백엔드: FastAPI + Python 3.11+ + SQLite (`backend/`)
- 프론트: Vanilla JS + Tailwind CDN (`frontend/`)
- 테스트: pytest
